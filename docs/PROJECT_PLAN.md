# Geetz LifeOS

## Overview

Geetz LifeOS is a premium full-stack personal productivity operating system.

The application combines:

- Dashboard

- Habit Tracker

- Daily Planner

- Goals & Achievements

- Health Dashboard

- Learning Hub

- Life Analytics

- Journal

- Reading Tracker

- Coding Tracker

- Notifications

- Settings

The UI has already been designed using Google Stitch.

The goal is to convert the exported Stitch HTML into a production-ready full-stack application without changing the UI.

## Development Rules

- Preserve the existing UI exactly.

- Build reusable components.

- Use clean architecture.

- Keep business logic separate from UI.

- Use TypeScript strict mode.

- Follow production-ready coding practices.
